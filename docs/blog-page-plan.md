# 개인 블로그 페이지 구조

## 페이지

- `index.html`: 게시글 목록, 검색, 카테고리 필터, 더 보기
- `post-detail.html`: 게시글 본문, 목차, 좋아요, 링크 복사
- `write.html`: 게시글 작성 및 브라우저 임시저장
- `profile.html`: 작가 소개, 경력, 관심 분야
- `login.html`: 로그인 폼
- `signup.html`: 회원가입 폼

## 공통 자원

- `css/style.css`: 블로그 전체 디자인과 반응형 레이아웃
- `js/main.js`: 모바일 메뉴, 목록 필터, 폼 검증, 글 작성 기능

현재 구현은 정적 프론트엔드 프로토타입이다. 실제 회원·게시글 데이터 저장과 발행을 위해서는 백엔드 API 연결이 필요하다.
