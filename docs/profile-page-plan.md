# 개인 프로필 페이지 기획 문서

## 1. 프로젝트 개요

HTML, CSS, JavaScript를 사용해 개인 프로필 페이지를 만든다. 사용자는 한 페이지에서 자기소개, 기술 스택, 프로젝트, 연락처 정보를 확인할 수 있어야 한다.

## 2. 목표

- 깔끔하고 보기 쉬운 개인 소개 페이지 제작
- 반응형 레이아웃 지원
- HTML, CSS, JavaScript 역할 분리
- 추후 포트폴리오 페이지로 확장 가능한 구조 구성

## 3. 권장 폴더 구조

```text
frontend/
  index.html
  css/
    style.css
  js/
    main.js
  assets/
    images/
      profile.jpg
docs/
  profile-page-plan.md
backend/
```

## 4. 페이지 구성

### 4.1 헤더

- 사이트 이름 또는 사용자 이름 표시
- 주요 섹션으로 이동하는 내비게이션 메뉴 제공
- 메뉴 예시:
  - 소개
  - 기술
  - 프로젝트
  - 연락처

### 4.2 메인 프로필 영역

- 프로필 사진
- 이름
- 직무 또는 관심 분야
- 짧은 소개 문구
- 주요 링크 버튼
  - GitHub
  - Blog
  - Email

### 4.3 자기소개 영역

- 간단한 자기소개
- 현재 공부 중인 분야
- 개발자로서의 관심사

### 4.4 기술 스택 영역

- 사용할 수 있는 기술 목록 표시
- 예시:
  - HTML
  - CSS
  - JavaScript
  - Git
  - React 또는 Node.js 등 추후 추가 가능

### 4.5 프로젝트 영역

- 프로젝트 카드 형태로 구성
- 각 프로젝트 카드에 포함할 정보:
  - 프로젝트 이름
  - 간단한 설명
  - 사용 기술
  - GitHub 또는 배포 링크

### 4.6 연락처 영역

- 이메일
- GitHub 링크
- 블로그 또는 SNS 링크
- 간단한 문의 문구

### 4.7 푸터

- 저작권 문구
- 제작 연도
- 사용자 이름

## 5. 디자인 방향

- 전체 분위기: 단정하고 현대적인 개인 포트폴리오 스타일
- 레이아웃: 한 페이지 스크롤 구조
- 색상: 흰색 또는 밝은 배경 기반, 강조 색상 1~2개 사용
- 폰트: 가독성 좋은 sans-serif 계열
- 카드 UI: 프로젝트와 기술 스택을 보기 쉽게 분리
- 모바일에서도 내용이 겹치지 않도록 반응형 처리

## 6. HTML 요구사항

- 시맨틱 태그 사용
  - `header`
  - `main`
  - `section`
  - `footer`
- 각 섹션에 명확한 `id` 부여
- 이미지에는 `alt` 속성 작성
- 외부 링크에는 적절한 텍스트 사용

## 7. CSS 요구사항

- `css/style.css` 파일에서 스타일 관리
- 공통 스타일 먼저 작성
  - `body`
  - `a`
  - `img`
  - 공통 컨테이너
- 섹션별 스타일 분리
- 모바일 화면 대응을 위한 미디어 쿼리 작성
- 버튼, 카드, 내비게이션에 hover 상태 추가

## 8. JavaScript 요구사항

- `js/main.js` 파일에서 동작 관리
- 구현할 수 있는 기능:
  - 내비게이션 클릭 시 부드러운 스크롤
  - 모바일 메뉴 열기/닫기
  - 프로젝트 카드 데이터 렌더링
  - 연락처 버튼 클릭 이벤트

## 9. 예시 콘텐츠

아래 내용은 구현 전 임시 데이터로 사용할 수 있다.

```text
이름: 홍길동
직무: 프론트엔드 개발자 지망생
소개: 사용자 경험을 생각하며 웹 인터페이스를 만드는 것을 좋아합니다.
기술: HTML, CSS, JavaScript, Git
이메일: example@email.com
GitHub: https://github.com/example
```

## 10. 구현 순서

1. `frontend/index.html` 생성
2. HTML로 전체 섹션 구조 작성
3. `frontend/css/style.css` 생성 후 기본 스타일 작성
4. 반응형 레이아웃 적용
5. `frontend/js/main.js` 생성 후 JavaScript 기능 추가
6. 브라우저에서 화면 확인
7. 실제 프로필 정보와 이미지로 교체

## 11. 완료 기준

- 브라우저에서 `index.html`을 열었을 때 페이지가 정상 표시된다.
- 헤더, 프로필, 소개, 기술, 프로젝트, 연락처, 푸터 영역이 모두 존재한다.
- 모바일과 데스크톱 화면에서 레이아웃이 깨지지 않는다.
- CSS와 JavaScript가 HTML과 정상 연결된다.
- 프로필 정보는 나중에 쉽게 수정할 수 있는 구조로 작성된다.
